# Списки просмотренного

Вспомнить, что смотрел, оценить и сравнить с друзьями. Одна страница, без сервера.

**Открыть:** https://goringoringorinich-wq.github.io/spiski/

- Отметки хранятся в браузере. Чтобы они были и на других устройствах — «Синхронизация» в профиле:
  код синхронизации вводится на втором устройстве (хранение — Firebase).
- Сравнить коллекции — «Сравнить с другом»: длинный ключ пересылается в мессенджере.
- Перенести коллекцию в другие Списки или сберечь — «Перенос коллекции» в профиле: выгрузить в файл и загрузить там.

## Источники

- Названия, годы, страны, люди: Wikidata (CC0), Википедия, Shikimori; популярность — открытые таблицы IMDb
  (некоммерческое использование).
- Афиши на сайте не хранятся: страница показывает их прямо с IMDb и Википедии по исходным адресам.
- Страница закрыта от поисковиков (`robots.txt` и `noindex`): открыта по ссылке, но специально её не найдут.
